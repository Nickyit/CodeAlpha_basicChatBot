# CodeAlpha Basic Chatbot

PyBot is a simple, interactive chatbot built with Python for the CodeAlpha Basic Chatbot task. It runs in the terminal and responds to common messages using predefined responses.

## Features

- Responds to greetings and common questions
- Remembers your name during the current session
- Includes a help menu and exit commands

## Requirements

- Python 3

No third-party packages are required.

## Run

```bash
python3 chatbot.py
```

Type `help` to see available commands. Enter `bye`, `exit`, or `quit` to end the conversation.
